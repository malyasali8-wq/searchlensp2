What is an Open Graph preview tool?

Open Graph (OG) tags decide how your link looks when it's shared on Facebook, LinkedIn, WhatsApp, Slack, Discord and X — the title, description and preview image. This tool reads your tags and shows you exactly how the share card will appear, plus flags any missing tags before you publish. No more blank thumbnails or wrong titles going out to thousands of feeds.

The Open Graph tags that matter

  • og:title — the bold headline on the card.
  • og:description — the supporting line beneath it.
  • og:image — the preview image; use 1200×630px. A missing image is the #1 reason share cards look broken.
  • og:url — the canonical URL being shared.
  • twitter:card — set to summary_large_image for a big image card on X.

How to add Open Graph tags

Place them inside the <head> of your page. Don't have them yet? Generate a full, correct set with our meta tag generator, which outputs OG and Twitter tags together with a live Google preview. After publishing, re-share the URL so platforms refresh their cached preview.

Frequently asked questions

Why does my link show no image when shared?

Almost always a missing or invalid og:image. Add an og:image tag pointing to a 1200×630 image, then re-share the URL so the platform refreshes its cache.

What size should the Open Graph image be?

1200×630 pixels is the standard that works across Facebook, LinkedIn and X. Keep important content away from the edges.

Do I need both Open Graph and Twitter tags?

Open Graph covers most platforms. X/Twitter also reads twitter:card (use summary_large_image). If Twitter tags are absent, X falls back to Open Graph, so OG is the priority.
