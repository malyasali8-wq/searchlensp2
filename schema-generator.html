What is schema markup?

    
Quick answer: schema markup is code that labels what a page is about, using the shared schema.org vocabulary, so search engines and AI answer engines can read it as structured facts instead of guessing. This free schema SEO tool writes it as JSON-LD, the format Google recommends.

    
Schema markup (structured data) is extra code that describes your page using the shared schema.org vocabulary. Visitors don't see it, but search engines and AI answer engines can read it to understand what a page is about — a product, an article, a business, an organization. When the markup is valid and the page follows Google's guidelines, the page may become eligible for rich results such as product details, review snippets or breadcrumbs. Google decides whether to show them, so eligibility is never a guarantee.


    
Why JSON-LD?

    
There are a few ways to add structured data, but JSON-LD is the format Google officially recommends. It's a single block of JSON inside a <script type="application/ld+json"> tag that sits separately from your visible HTML. That separation makes it easy to add, read and maintain — you don't have to weave attributes through your markup. This generator always outputs clean JSON-LD.


    
Which schema type should I use?

    
    
      
  • Organization — your company's name, logo, URL and social profiles. Add it site-wide (usually the homepage).
    • 
      
  • LocalBusiness — for businesses with a physical location: address, phone, opening hours, geo.
    • 
      
  • Article / BlogPosting — for blog posts and news: headline, author, dates, image.
    • 
      
  • Product — for e-commerce: name, image, brand, price and availability.
    • 
      
  • FAQPage — a list of question and answer pairs. Google stopped showing FAQ rich results in May 2026, but FAQPage is still a valid schema.org type that labels Q&A content clearly for any system that reads it.
    • 
      
  • WebSite — declares your site name and URL. Google retired the sitelinks search box in 2024, so the optional search field only adds a SearchAction that other tools may read.

JSON-LD schema example

    
This is the kind of code the JSON-LD schema generator produces. It is a complete Organization block, ready to paste into a page:


<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Organization",
  "name": "Example Co",
  "url": "https://www.example.com",
  "logo": "https://www.example.com/logo.png",
  "sameAs": ["https://www.linkedin.com/company/example"]
}
</script>

    
    
      
  • @context tells readers the vocabulary is schema.org.
    • 
      
  • @type says what the page entity is. Every block needs one.
    • 
      
  • name, url and logo describe the organization. Use full, absolute URLs.
    • 
      
  • sameAs lists your official profiles, which helps search and AI systems connect them to one entity.
    •

People often search for a "rich snippets generator". Rich snippets, now called rich results, are enhanced search listings. A generator can only write the markup. Whether Google shows a rich result depends on the type and on Google's current rules, which change over time. For the types in this tool:

    
    
      
  • Product: can be eligible for product details such as price and availability. Review stars also need review or rating data, which this form does not create.
    • 
      
  • Article: helps Google understand the headline, author and dates.
    • 
      
  • Organization, LocalBusiness and WebSite: mainly help search engines understand your business and site. Treat them as clarity markup, not a ticket to a rich result.
    • 
      
  • FAQPage: no longer produces an FAQ rich result in Google.

Valid schema markup vs rich result eligibility

    
Valid means the code parses as JSON and follows the schema.org vocabulary. Eligible means the page also meets the extra requirements Google sets for a specific rich result, and the markup matches content visitors can see. Valid code can still be ineligible, and neither one guarantees that Google shows anything. Check syntax and properties with the schema markup validator, then test eligibility with Google's Rich Results Test.

  • Dates: use the ISO format, for example 2026-11-26.
    • 
      
  • Price: type the number only, such as 29.99, and put the currency in its own field.
    • 
      
  • Images and logos: use full URLs that start with https and open in a browser.
    •

Frequently asked questions

    

      
Does schema markup directly improve rankings?
It isn't a direct ranking factor. It helps search engines and AI engines understand your content, and where Google supports a rich result, valid markup can make the page eligible for it. Neither is a promise of higher rankings.

      
Where should the JSON-LD go?
Inside the <head> is cleanest, though Google also reads it in the body. Put each type on the page it describes.

      
Can I use more than one schema type on a page?
Yes. A blog post can have both Article and FAQPage, for example. Add multiple script blocks, or combine them in one @graph.

      
Is this generator free?
Yes — generating, copying and downloading is completely free and runs entirely in your browser. Nothing is uploaded.

      
How do I add schema markup to my website?
Generate the JSON-LD here, copy it, and paste it inside a script tag of type application/ld+json in the head or body of the page. Then test the page with Google's Rich Results Test.

      
What is the difference between schema markup and structured data?
Structured data is the general idea of labelling page content in a machine-readable way. Schema.org is the shared vocabulary, and JSON-LD is the format Google recommends for writing it.

      
What is a JSON-LD schema generator?
A JSON-LD schema generator turns the details you type into a script tag of structured data. You copy the tag into your page instead of writing the JSON by hand.

      
Is this a Google schema generator?
It writes schema.org JSON-LD, the format Google recommends, but it is an independent SEOGlint tool and not made by Google. To see whether Google can use the markup on a page, test it with Google's Rich Results Test.

      
Does valid schema markup mean I will get rich results?
No. Valid markup can make a page eligible for some rich results, but Google decides what to show, and not every schema type has a rich result.

      
Can I still get FAQ rich results?
Not in Google. Google stopped showing FAQ rich results in May 2026. FAQPage is still a valid schema.org type, so existing markup is harmless.
