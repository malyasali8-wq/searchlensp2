Free Sitemap Checker: validate your sitemap.xml

Paste your sitemap and check the XML, URL count, duplicates, dates and size limits before you submit it to Google and Bing. It runs in your browser.

What is a sitemap checker?

A sitemap checker tests a sitemap.xml file against the sitemap protocol, the format search engines read to discover your pages. Catching errors before you submit saves time in Search Console, where a bad sitemap shows up as "Couldn't fetch" or "Has errors".

What this sitemap checker tests

  • Valid XML and a correct urlset or sitemapindex root.
  • URLs: absolute http or https, no spaces, no duplicates, one host.
  • Limits: up to 50,000 URLs and 50 MB uncompressed per file.
  • Tags: lastmod date format, priority range and changefreq values.

Sitemap best practices

  • List only canonical, indexable URLs that return 200.
  • Keep lastmod accurate, and only change it when the page really changes.
  • Reference the sitemap in robots.txt with a Sitemap: line.
  • Submit it in Google Search Console and Bing Webmaster Tools.

Why an SEO sitemap matters

An SEO sitemap tells search engines which URLs you want them to find, and when they last changed. It matters most for new sites, large sites and pages with few internal links. It is a hint, not a command, but a clean sitemap makes discovery faster and makes problems easy to spot in Search Console.

Ecommerce sitemap tips

  • Include product, category and key content pages that you want indexed.
  • Leave out filtered, sorted and session URLs that create duplicates.
  • Split large catalogs into several sitemaps and list them in a sitemap index.
  • Remove products that are permanently gone, or redirect them.

Common sitemap errors and fixes

  • Not valid XML: an unescaped & or an unclosed tag. Use &amp; in URLs.
  • Duplicate URLs: keep one canonical version of each page.
  • Wrong host or http URLs: list only URLs that match your preferred https host.
  • Bad lastmod: use the W3C format, like 2026-11-20.

Sitemap changefreq and priority

The changefreq and priority tags are optional, and Google has said it does not use them. Keep them valid if you include them, and focus on an accurate lastmod.

Frequently asked questions

What is a sitemap checker?

A sitemap checker reads your sitemap.xml and tests it against the sitemap protocol: valid XML, a urlset or sitemapindex root, absolute URLs, valid dates and the size limits.

How do I check my sitemap.xml?

Open your sitemap in a browser, copy the XML, paste it into the box above and press Check. Errors and warnings are listed with the URL they apply to.

What are the sitemap limits?

A single sitemap file can hold up to 50,000 URLs and must be no larger than 50 MB uncompressed. Larger sites split into several sitemaps listed in a sitemap index.

Does a sitemap guarantee my pages get indexed?

No. A sitemap helps search engines discover URLs, but indexing is decided by quality, duplicates and crawl access. Check coverage in Google Search Console.

Do changefreq and priority matter?

Google has said it ignores priority and changefreq. The lastmod date is used when it is accurate. Keeping the other tags valid is harmless.

Can this tool fetch my sitemap by URL?

Not at the moment. Browsers block fetching other sites, so paste the XML instead. The check runs locally and nothing is uploaded.

What should an XML sitemap include?

Only canonical, indexable URLs that return a 200 status, ideally with an accurate lastmod date. Leave out redirects, noindex pages and duplicates.

Where do I submit my sitemap?

Add it in Google Search Console and Bing Webmaster Tools, and reference it in robots.txt with a Sitemap line.
