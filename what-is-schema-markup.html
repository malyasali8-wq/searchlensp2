What is schema markup? Schema explained

By Muhammad Ilyas

Schema markup is the code that tells search engines and AI what your page means. Here is what it is, why it matters and how to add it.

What is schema?

Schema, or schema markup, is a standard vocabulary from schema.org that you add to a page as structured data. It labels your content so a machine can tell that a number is a price, a name is an author or a block of text is a question and its answer. The preferred format is JSON-LD.

What is schema in SEO?

In SEO, structured data helps search engines understand a page and can make it eligible for richer search results. Google does not treat it as a direct ranking factor, but clear markup removes guesswork, and AI answer engines also read it when they gather facts.

Schema markup example

A simple Organization schema in JSON-LD looks like this:

<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Organization",
  "name": "Example Co",
  "url": "https://www.example.com/",
  "logo": "https://www.example.com/logo.png"
}
</script>

Each block has an @context, a @type and properties that describe the thing.

Common schema types

  • Organization and WebSite: who you are and what the site is.
  • Article and BlogPosting: headline, author and dates for posts.
  • Product and Offer: name, image, price and availability.
  • FAQPage: real questions and answers shown on the page. See the FAQ schema generator.
  • BreadcrumbList: the path to a page.

How to add schema markup

  1. Pick the type that matches the page.
  2. Create the JSON-LD with the schema markup generator.
  3. Paste the script block into the page head or body.
  4. Check it with the schema markup validator and Google's Rich Results Test.

The markup must match what visitors can see on the page. Marking up hidden or false content can lead to a manual action.

Schema and AI search

AI answer engines work with clear facts, and structured data supplies labelled ones. It is one part of getting cited, along with crawl access and answer-first content. Read more in our GEO guide.

Schema markup vs structured data

The two terms are used almost interchangeably. Structured data is the general idea of labelling content in a machine-readable way. Schema markup is structured data that uses the schema.org vocabulary. JSON-LD is the format used to write it.

Benefits of schema markup

  • Clearer meaning: search engines know what each part of the page is.
  • Rich result eligibility: some types, such as Product, Recipe and Event, can earn richer listings if Google chooses to show them.
  • Useful for AI: labelled facts are easy for answer engines to read.
  • Consistency: it forces you to state your name, logo and details in one standard way.

What is schema in SEO terms for a small site?

For a small site, a few types cover most needs: Organization and WebSite on the home page, Article on posts and BreadcrumbList for navigation. You do not need to mark up everything. Accurate markup on your main pages beats a large amount of careless markup.

Frequently asked questions

What is schema markup?

Schema markup is code, usually JSON-LD, added to a page that labels its content in a standard vocabulary from schema.org, so search engines and AI can understand what the page is about.

What is schema in SEO?

In SEO, schema is structured data that describes your page: who published it, what the product is, what questions it answers. It helps search engines interpret content and can make results richer.

Is schema markup a ranking factor?

Google says structured data is not a direct ranking factor, but it helps it understand pages and can make a page eligible for rich results. Rankings still depend on content quality and relevance.

What is the best format for schema markup?

JSON-LD. Google recommends it, it sits in one script block and does not change your visible HTML. Microdata and RDFa are also supported.

Which schema types should I use first?

Start with Organization and WebSite on the home page, Article or BlogPosting for posts, Product for products and BreadcrumbList for navigation. Add FAQPage where you really have visible questions and answers.

How do I test my schema markup?

Paste it into the SEOGlint schema markup validator for a quick check, then test the live page in Google's Rich Results Test.

Do I need a developer to add schema markup?

No. You can create JSON-LD with a generator and paste it into the page. A developer is only needed if you want it generated automatically on a large site.
