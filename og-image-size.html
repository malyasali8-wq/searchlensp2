Best OG image size: dimensions for every platform

The right Open Graph image size, ratio and tag for Facebook, LinkedIn and X, so your links always show a clean preview.

OG image size at a glance

Facebook and most sites1200 x 630 px1.91:1

Platforms change their guidance, so confirm the current numbers in each platform's documentation.

What is an OG image?

An OG image, or Open Graph image, is the picture shown when your link is shared on social networks and in chat apps. You set it with the og:image meta tag. The tags are part of what we call OG meta tags: og:title, og:description, og:image and og:url.

How to set the og:image tag

<meta property="og:image" content="https://www.example.com/og-image.png">
<meta property="og:image:width" content="1200">
<meta property="og:image:height" content="630">
<meta name="twitter:card" content="summary_large_image">

Use a full absolute URL, not a relative path. Build the complete set with the meta tag generator.

OG image tips

  • Keep key text and logos in the middle, away from the edges that some platforms crop.
  • Use a clear, high contrast image with large text. It is often seen as a small thumbnail.
  • Keep the file reasonably small, as large files can fail to load in previews.
  • Give every important page its own image where you can.

Test your OG image

Paste your tags into the OG meta tags checker to preview the card and see missing tags. Platforms cache old previews, so use their debugger tools to refresh after a change.

OG tags you need besides og:image

A full set of OG meta tags makes your shared links look right. These are the core ones:

  • og:title: the headline shown on the card.
  • og:description: a short summary.
  • og:url: the canonical address of the page.
  • og:type: the kind of content, usually website for a home page and article for posts.
  • og:image: the preview picture.

OG type explained

The OG type tells platforms what the page is. Use website for general pages and article for blog posts and news. Other values exist for products, profiles and media, but these two cover most sites.

Common OG image problems

  • The image URL is relative instead of absolute.
  • The image is too small, so the card shows a tiny thumbnail.
  • The image is blocked by robots.txt or needs a login.
  • An old preview is cached, so the new image does not appear yet.

Frequently asked questions

What is the best OG image size?

1200 x 630 pixels, a 1.91:1 ratio, is the safe size for Facebook, LinkedIn and most platforms. Use a PNG or JPG and keep important content away from the edges.

What is the minimum Open Graph image size?

Facebook accepts images from 200 x 200 pixels, but small images show as tiny thumbnails. For a large preview card, use at least 600 x 315 and aim for 1200 x 630.

What OG image size does X (Twitter) use?

For the summary_large_image card, X uses a 2:1 ratio such as 1200 x 600. A 1200 x 630 image also works, with the edges cropped slightly.

What is the OG image size for LinkedIn?

LinkedIn recommends 1200 x 627 pixels, which is the same 1.91:1 ratio as the Facebook size.

How do I set an OG image?

Add <meta property="og:image" content="https://yoursite.com/image.png"> to the page head, using a full absolute URL. Generate all the tags with the meta tag generator.

Why is my OG image not showing?

Common causes are a relative URL, an image that is too small or too large in file size, a blocked image URL, or a cached old preview. Test it in the Open Graph preview tool.

What is og:type?

og:type tells platforms what kind of content a page is. Use website for general pages and article for posts. It is one of the core OG tags along with og:title, og:description, og:url and og:image.

Which OG tags are required?

The core set is og:title, og:type, og:image and og:url. Adding og:description is also strongly recommended.
